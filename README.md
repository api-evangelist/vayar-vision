# Vayar Vision

Vayar Vision Ltd was an Israeli startup (incorporated 2007, Herzliya) that developed a visual search engine enabling search for images based on their visual characteristics rather than textual tagging. Surfaced as a Battery Ventures portfolio company (listed as an exited investment), it has since been wilfully dissolved and its former website vayar.com no longer resolves. No API surface, developer program, or published artifacts exist.
